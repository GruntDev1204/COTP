Details about COTP :
    - COTP (Chaos-One-Time-Prompt) :
    * Origin & Philosophical Inspiration: Formulated by Ho Trung (Grunt), born December 4, 2001, a Da Nang native and Electronics & Telecommunications Engineer from DUT CLC (Da Nang University of Technology - High-Quality Program). The theorem is deeply inspired by the principle of "Non-Abiding Wisdom" (Vô Sở Trụ) of Shakyamuni Buddha (Ho Trung's supreme idol), manifested through the doctrine of "Skillful Expedient Means" (Phương Tiện Thiện Xảo)—utilizing pure, unattached randomness as an effortless vehicle to transcend rigid cognitive boundaries.
    * Theorem Statement: Let S be an invariant syntactic structure with n independent variable slots {X_1, X_2, ..., X_n}, where each X_i corresponds to a discrete semantic pool D_i with cardinality |D_i| = k_i. Performing simultaneous, seedless random selection across all X_i induces a combinatorial explosion in the output sample space Ω, defined by the product:

        |Ω| = ∏_{i=1}^{n} k_i
    From a finite, simple structure, the system yields an astronomical set of unique variants without complex semantic inference algorithms.
    * Corollaries (as execution count N → ∞):
    1. Maximum Entropy & Indeterminacy: Maximizes output entropy H(Ω), nullifying determinism and predictability for both linear human cognition and statistical AI models.
    2. Semantic Collision & Creative Mutation: Forcing unrelated entities to co-occur within S breaks associative inertia, inevitably generating surreal, novel combinations.
    3. Static Filter Neutralization: Lexical fragmentation and one-time composition defeat static keyword-matching and rigid contextual filters.
    4. Paradigm Shift in Creation: Shifts the subject's role from manual content generator to structural architect (S) and output curator within an infinite probability space.

    App : is a desktop app that creates a new text prompt when you click CREATE.
    Choose a prompt type, or select RANDOM to first pick one of the available types: Indoor Scene, Outdoor Scene, Couple Prompt, Modeling Prompt, L4D2 Rule, App Date Options,
    or one of four Short Stories. Each generator fills its template by randomly selecting values from the app's predefined data arrays and, where needed, generating random numbers.
    Indoor and Outdoor scenes combine locations with their corresponding setting details, objects, NPCs, actions, and other descriptive elements; the other generators build their
    own prompt formats. The generated text is shown in the app and can be copied. COTP only creates the text—it does not send it to or run it through an AI. It does not set a fixed
    random seed or save generated prompts; each click generates a fresh result.

How to use COTP :
    1/ Start the app by running main.py, or open the executable if you have built one.
    2/ In the Prompt menu, choose the kind of prompt you want. Choose RANDOM (the default) to let COTP select a prompt type for you.
    3/ Click CREATE. The generated prompt will appear in the large text box. Click CREATE again whenever you want a different result.
    4/ Click Copy Output to copy the displayed prompt to your clipboard, then paste it wherever you want to use it.
    5/ The CREATE PRESSES counter shows how many times you have generated a prompt in the current app run. It is not saved and resets when you close and reopen COTP.
    6/ Optional: use the theme switch to change the app's appearance, or choose Stats, Arrays COTP, or COTP Struct Details from the Info menu to view app information.

Project folder structure :
    - data/ : prompt data pools, including Indoor and Outdoor locations, NPCs, actions, stories, icons, and other choices.
    - Script/ : functions that assemble prompt text from the data pools and generate randomized values.
    - ui/ : the Tkinter interface, menu options, theme colors, and other UI properties.
    - log/ : statistics, array diagnostics, and the COTP Struct Details generator.
    - main.py : application entry point.
    - COTP - CHAOS ONE TIME PROMPT.spec : generated by the PyInstaller command above; it records the build settings, including the bundled data/ and Script/ source files.
    - instruction.txt : build and usage instructions.
    - build/ and dist/ : generated by PyInstaller; build/ contains temporary build files and dist/ contains the finished executable.
